maai

A Wayland terminal emulator built in Zig — PTY, VT parser, GPU-rendered text, and nothing you did not ask for.

Zig Wayland / EGL OpenGL Linux MIT License
About

maai opens a window, spawns a shell, and stays out of the way. Under the hood: a PTY read loop, a VT sequence parser, a glyph atlas on the GPU, and a Wayland surface driven by poll(2) — no threads, no framework, one tight event loop. Config is a flat key value file; themes are compatible with the corpus already out there. Edit either one and the change lands while you watch.

Features
Tabs
Up to 32 tabs per window. New tab inherits the current directory.
Control socket
One socket per window under $XDG_RUNTIME_DIR. Ask it to focus the tab running on a given pty.
Window identity
Title follows the active tab's OSC title. --app-id gives one window its own compositor rules.
Powerline bar
Shaped separators between tabs. Angled, slanted, or round — needs a Nerd Font.
Hint mode
Every visible link labelled. Type two letters to open or copy — no mouse required.
URL handling
OSC 8 hyperlinks and plain-text URL detection. Ctrl+click opens; shift-click copies.
Live reload
Config, theme file, and flavour file are watched via inotify. Save to apply.
Mouse protocols
All xterm mouse modes. Shift overrides back to selection in any mode.
GPU rendering
Glyph atlas rasterised once, drawn each frame via OpenGL/EGL. No compositing path.
Scrollback
10 000 lines by default (configurable). Ring buffer; no allocation on scroll.
Default bindings
Combination Action
Ctrl+Shift+CCopy selection to clipboard
Ctrl+Shift+VPaste from clipboard
Ctrl+Shift+UEnter hint mode
Ctrl+Shift+TNew tab
Ctrl+TabNext tab
Ctrl+Shift+TabPrevious tab
Alt+1…0Jump to tab by number row position
Alt+%New window in current directory
Shift+Page Up/DownScroll half a page

Every binding is remappable. Use key <combo> none to hand a combination back to applications.

Configuration
~/.config/maai/maai.conf
# font and layout
font_family  FiraCode Nerd Font Ret
font_size    12
padding_x    4

# behaviour
copy_on_select    yes
scrollback_lines  10000
url_launcher      xdg-open

# tab bar
tab_bar_style      powerline
tab_powerline_style slanted

# theme — name looked up in theme_dir, or a path
theme  nightfox
# or let an external switcher drive it:
theme_flavour_file  ~/.config/.app-theme-flavour

# rebind or free a key
key  ctrl+shift+c  copy
key  ctrl+tab      none  # hand back to applications
Build & install
01
$ git clone <repo> && cd maai
02
$ zig build -Doptimize=ReleaseFast
03
$ ./zig-out/bin/maai
or
$ bash install.sh

Requires Zig 0.16+, libwayland-client, libEGL, libxkbcommon, and fcft.
